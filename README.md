# FraudGuard ML

FraudGuard ML is a cost-aware fraud detection system
built using Machine Learning and XGBoost.

## Features

- Fraud Detection
- Risk Scoring
- Cost-Sensitive Learning
- XGBoost Classification
- SMOTE Oversampling
- Feature Importance
- Flask API
- Streamlit Dashboard
- Explainable AI

## Tech Stack

- Python
- Scikit-learn
- XGBoost
- Flask
- Streamlit
- SHAP

## Run Project

python main.py

## Run Dashboard

streamlit run dashboard/streamlit_app.py

## Run API

python api/app.py
